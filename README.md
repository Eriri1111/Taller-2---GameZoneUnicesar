# GameZone Unicesar A Java-based enterprise management system designed for **GameZone Unicesar**, a video game and console retail store located in the university sector of Valledupar, Colombia [cite: 1]. The system modernizes manual operations by providing structured inventory management, customer and employee relationship tracking, and secure sales transaction processing built upon a strict four-layer architecture [cite: 1]. --- ## Architectural Overview The application strictly implements a **layered architecture** to separate concerns, enforce maintainability, and guarantee clean object-oriented design principles [cite: 1]: * **`com.gamezone.model`**: Contains domain entities, abstract base classes, and business objects with private attributes and encapsulated behavior [cite: 1]. * **`com.gamezone.persistence`**: Manages file-based data persistence, ensuring information survives application reboots without leaking business logic [cite: 1]. * **`com.gamezone.service`**: Encapsulates core business rules, transactional verifications (such as inventory stock checks and minimum product rules), and data processing workflows [cite: 1]. * **`com.gamezone.ui`**: Provides a clean console-based user interface supporting interactive menus and formatted data views [cite: 1]. * **`com.gamezone.Main`**: Entry point that coordinates application bootstrapping and dependency injection across layers [cite: 1]. --- ## System Features & Functional Operations The console interface offers ten core operations grouped by functional modules [cite: 1]: ### Product Management 1. **Register a new video game**: Input platform, genre, and age rating alongside common product attributes. 2. **Register a new console**: Input brand, model, and generation details. 3. **List all inventory products**: View complete real-time stocks and product specifics. ### Person Management 4. **Register a new customer**: Collect basic contact details and track purchase history. 5. **List all registered customers**: View complete client database. 6. **List all registered employees**: View staff details, employee codes, and shift schedules (includes preloaded staff data). ### Sales & Transaction Management 7. **Register a new sale**: Process transactions linking a customer, a staff member, and one or more products with automated stock reduction and total calculation [cite: 1]. 8. **View complete sales history**: Audit all past transactions. 9. **View customer purchase history**: Query individual client buying records. 10. **View employee sales history**: Audit transactions handled by specific staff members. --- ## Getting Started & Installation ### Prerequisites * **Java Development Kit (JDK 17 or higher)** * **Apache Maven** installed and configured in your system path. ### Compilation and Execution 1. Clone the repository and navigate to the project root directory: ```bash git clone https://github.com/Eriri1111/Taller-2---GameZoneUnicesar.git cd Taller-2---GameZoneUnicesar ``` 2. Build the project dependencies and package the application using Maven: ```bash mvn clean compile package ``` 3.
